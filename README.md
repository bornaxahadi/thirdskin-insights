# Third Skin Insights

Private live dashboard for https://thirdskin.online (not indexed by search engines).

- `index.html` – the mobile-first dashboard (reads `data.json`).
- `data.json` – written by `collector.py` (Google Analytics 4 property 557594788 + live site checks).
- `collector.py` – runs in the Composio remote workbench (`exec` it there); refreshes `data.json` in this repo.
